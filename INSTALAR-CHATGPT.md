# Usar Xquads con ChatGPT

1. Descarga `xquads-es-chatgpt.txt` desde Releases, sin necesidad de un ZIP.
2. Adjunta ese archivo a una conversación nueva de ChatGPT.
3. Escribe: «Activa Xquads con las instrucciones del archivo y muéstrame los
   equipos disponibles». Después, describe tu objetivo.

El archivo contiene las instrucciones y los 15 equipos. No necesitas copiar
código, crear un repositorio ni utilizar la terminal. Puedes guardarlo en un
proyecto para reutilizarlo si tu cuenta dispone de esa función.

No subas el ZIP entero como si fuera una extensión: extráelo primero. Estos son
archivos de contexto e instrucciones, no un plugin ni una instalación nativa
de Agent Skills en ChatGPT. Las funciones y límites de archivos dependen de tu
cuenta. Como alternativa para cuentas con límites bajos o para tareas focalizadas,
el ZIP incluye `INSTRUCCIONES.txt` y documentos separados por equipo: adjunta
solo `conocimiento/xquads.txt` y el equipo que quieras usar, y copia las instrucciones.

Fuente oficial: https://learn.chatgpt.com/docs/use-chatgpt
