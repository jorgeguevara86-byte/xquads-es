# Instalar en Claude

1. Descarga `xquads-es-claude.zip` desde Releases. No uses para esto el ZIP del
   repositorio completo ni el ZIP de ChatGPT.
2. En Claude, abre Customize → Skills (la ubicación puede cambiar según cuenta).
3. Selecciona la opción para subir una skill y elige ese ZIP sin descomprimirlo.
4. Activa **xquads-es**. Ejemplo: «Usa Xquads para mejorar mi estrategia de marca».

El ZIP contiene una sola carpeta raíz `xquads-es/` con `SKILL.md` y los 15 equipos
como referencias locales. Requiere que tu cuenta tenga habilitada la función
de skills personalizadas. No es una instalación de un servidor ni un plugin MCP.
Se verificó el formato del paquete; la activación en tu cuenta aún debe probarse.

Fuente oficial: https://support.claude.com/en/articles/12512198-how-to-create-custom-skills
