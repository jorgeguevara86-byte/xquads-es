# Xquads en español

15 equipos de agentes de IA para marketing, copywriting, marca, publicidad,
ofertas, diseño, datos, narrativa, estrategia y seguridad autorizada.

Adaptación al español del [proyecto original](https://github.com/ohmyjahh/xquads-squads).
Se conserva la autoría original; no es una versión oficial de OpenAI o Anthropic.

## Descarga y uso

**¿Quieres usarlos globalmente en tu computadora?** Copia el
[prompt de instalación global](PROMPT-INSTALACION-GLOBAL.txt) en una aplicación
con acceso a tu terminal. [Guía y compatibilidad](INSTALAR-GLOBAL.md).

- **ChatGPT Work (aplicación de escritorio):** [guía de instalación](INSTALAR-WORK.md)
  y [plugin de 15 skills](https://github.com/jorgeguevara86-byte/xquads-es/releases/latest/download/xquads-es-work-plugin.zip).
  Tras instalar, selecciona los equipos con **@**.
- **Claude Code:** pega el [prompt global](PROMPT-INSTALACION-GLOBAL.txt).
  Tras instalar, escribe **/** y elige un squad.

### Alternativas para chats sin instalación global

- **Claude:** [descargar skill ZIP](https://github.com/jorgeguevara86-byte/xquads-es/releases/latest/download/xquads-es-claude.zip)
  → [guía de instalación](INSTALAR-CLAUDE.md).
- **ChatGPT:** [descargar un solo TXT](https://github.com/jorgeguevara86-byte/xquads-es/releases/latest/download/xquads-es-chatgpt.txt)
  → adjúntalo y escribe **«Activa Xquads»**. [Guía](INSTALAR-CHATGPT.md).
  Es un archivo de instrucciones y conocimiento, no un plugin ni una skill nativa.
- **Todo el contenido:** [descargar ZIP completo](https://github.com/jorgeguevara86-byte/xquads-es/releases/latest/download/xquads-es-completo.zip).
- **Terminal / clientes Agent Skills:** consulta [la guía técnica original traducida](README-TECNICO.md).

La descarga es pública. La disponibilidad de cargas de archivos, proyectos o
skills personalizadas depende de la cuenta de cada plataforma. El empaquetado
se validó localmente; no se verificó su activación dentro de una cuenta de Claude
o ChatGPT. No incluye acceso a APIs, servicios externos ni suscripciones.

## Equipos incluidos

- **advisory-board** — Consejo estratégico y decisiones empresariales.
- **brand-squad** — Marca, posicionamiento, identidad y naming.
- **c-level-squad** — Dirección ejecutiva, estrategia y operaciones.
- **claude-code-mastery** — Configuración y flujos de trabajo de agentes de código.
- **copy-master** — Copywriting avanzado y persuasión.
- **copy-squad** — Textos de venta y marketing.
- **cybersecurity** — Seguridad, auditorías y pruebas autorizadas.
- **data-squad** — Datos, crecimiento, retención y comunidad.
- **design-squad** — Diseño UX/UI y sistemas de diseño.
- **hormozi-squad** — Ofertas, precios, captación y ventas.
- **marketing-squad** — Campañas integradas de marketing.
- **movement** — Movimientos, causas, comunidades e identidad.
- **storytelling** — Narrativas, presentaciones y discursos.
- **traffic-masters** — Publicidad de pago y optimización de campañas.
- **xquads** — Diagnóstico y selección del equipo apropiado.
