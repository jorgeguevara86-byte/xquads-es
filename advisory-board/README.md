# Consejo Asesor

Tablero virtual de 11 pensadores y líderes estratégicos world-class .

## Inicio rápido

```
@board-chair # Activar el orquestador
*diagnose # Clasifique su pregunta estratégica
*board-meeting # Sesión completa del consejo asesor
*decision-framework # Análisis de decisión estructurada
```
