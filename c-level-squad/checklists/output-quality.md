# Lista de verificación de calidad de resultados de la estrategia ejecutiva

**ID de lista de verificación:** CLEVEL-CL-001
**Referenciado por:** tasks/review.md
**Propósito:** Validar la calidad de los entregables de la estrategia ejecutiva antes de entregarlos al usuario.

[[LLM: INSTRUCCIONES DE INICIALIZACIÓN

Esta lista de verificación valida específicamente los resultados de la estrategia ejecutiva.

ENFOQUE DE EJECUCIÓN:
1. Para cada categoría, verifique cada artículo con el entregable.
2. Marcar elementos como [x] Pasa, [ ] Falla, [N/A] No aplicable

## 1. Alineamiento Estratégico

- [ ] La estrategia se alinea con la misión, visión y long-term objetivos de la empresa (CRÍTICO)
- [ ] Se aborda el posicionamiento competitivo: ¿dónde jugamos y cómo ganamos? (CRÍTICO)
- [ ] La dinámica del mercado y las tendencias de la industria se tienen en cuenta
- [ ] La estrategia se basa en las fortalezas existentes en lugar de ignorarlas
- [ ] trade-offs estratégicos son explícitos: ¿qué elegimos NO hacer?

## 2. Implicaciones financieras

- [ ] El impacto en los ingresos se cuantifica o estima con los supuestos establecidos (CRÍTICO)
- [ ] Se aborda la estructura de costos: inversión requerida, costos continuos, break-even
- [ ] El retorno de la inversión o el período de recuperación se calcula cuando corresponda
- [ ] Se consideran las implicaciones del flujo de caja, no solo las pérdidas y ganancias
- [ ] Modelado de escenarios: mejor caso, caso base, peor caso con resultados financieros

## 3. Evaluación de riesgos

- [ ] Los riesgos clave se identifican en todas las dimensiones: mercado, operativo, financiero, regulatorio (CRÍTICO)
- [ ] Cada riesgo tiene una evaluación de probabilidad e impacto
- [ ] Se definen estrategias de mitigación o planes de contingencia
- [ ] Se consideran escenarios de respuesta competitiva
- [ ] Se identifican dependencias y puntos únicos de falla

## 4. Viabilidad de ejecución

- [ ] La línea de tiempo es realista con hitos graduales (CRÍTICO)
- [ ] Se especifican los requisitos de recursos: personas, presupuesto, tecnología, asociaciones.
- [ ] Se evalúa la brecha de capacidades organizacionales: ¿tenemos lo que necesitamos?
- [ ] Se abordan las consideraciones de gestión de cambios
- [ ] Se identifican victorias rápidas para generar impulso junto con long-term jugadas

## 5. Gobernanza y rendición de cuentas

- [ ] Los derechos de decisión son claros: quién aprueba, quién ejecuta, quién es consultado (CRÍTICO)
- [ ] Los KPI y las métricas de éxito se definen con objetivos
- [ ] Se establece la cadencia de revisión: ¿cuándo comprobamos el progreso?
- [ ] Se definen rutas de escalada para bloqueadores
- [ ] Estructura de responsabilidad: propietarios designados para cada flujo de trabajo

## 6. Comunicación y partes interesadas

- [ ] El impacto de las partes interesadas se mapea en toda la organización
- [ ] Board/investor se considera la narrativa cuando sea relevante
- [ ] Se detalla plan de comunicación interna
- [ ] Se abordan las implicaciones de cara al cliente
- [ ] El resumen ejecutivo es nítido y decision-ready

## PASS/FAIL Criteria

**APROBADO:** Todos los elementos CRÍTICOS [x] y menos de 3 fallas de non-critical .
**REVISIÓN:** Todos los elementos CRÍTICOS [x] pero más de 3 fallas de non-critical .
**FALLO:** Cualquier elemento CRÍTICO sin marcar.
