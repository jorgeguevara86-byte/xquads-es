# Cybersecurity Squad

15 agentes para operaciones de seguridad ofensivas y defensivas.

## Inicio rápido

```
@cyber-chief         Activar el orquestador
*diagnose            # Triage your security challenge
*pentest-engagement  # Ejecutar una prueba de penetración
*incident-response   # Maneje un incidente de seguridad
```
