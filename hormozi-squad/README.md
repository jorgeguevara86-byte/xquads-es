# Hormozi Squad

16 agentes especializados implementando los marcos de escala de negocios de Alex Hormozi.

## Inicio rápido

```
@hormozi-chief       Activar el orquestador
*diagnose            # Triage your business challenge
*business-turnaround # Full business turnaround workflow
*offer-pipeline      # End-to-end oferta creación
```
