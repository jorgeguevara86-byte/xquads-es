# Equipo de marca

El equipo de estrategia de marca definitivo: 10 pensadores de marca legendarios + 4 especialistas funcionales + 1 orquestador.

## Inicio rápido

```
@brand-chief # Activar el orquestador
*diagnose # Clasifica el desafío de tu marca
*brand-creation # Fin- Flujo de trabajo de creación de marcato-end 
*rebrand # Cambiar el nombre de una marca existente
```

## Components

- **15 agentes** — 1 orquestador + 10 pensadores + 4 especialistas
- **9 tareas** — audit-brand, diagnosticar, revisar, create-positioning, generate-names, build-identity, create-brand-story, design-architecture, map-archetype
- **2 flujos de trabajo**: brand-creation (completo), cambio de marca (marcas existentes)
- **1 checklist** — output-quality
- **2 archivos de datos** — brand-frameworks, routing-catalog

## Workflows

### Creación de marca (`*brand-creation`)
Fin-to-end: arquetipo > posicionamiento > naming > identidad > historia > paquete de lanzamiento.

### Rebrand (`*rebrand`)
Auditoría > revisión de posicionamiento > actualización de identidad > actualización de mensajes.

## Requirements

- AIOS >= 4.0.0
