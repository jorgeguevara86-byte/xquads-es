# Equipo de nivel C

C-suite virtual de 6 agentes de liderazgo ejecutivo.

## Inicio rápido

```
@vision-chief # Activar al CEO
*diagnose # Clasifica tu desafío ejecutivo
*strategic-planning # Planificación estratégica completa
*board-presentation # Preparar una presentación para el tablero
```

## Agents (6)

- **vision-chief** — Director ejecutivo/orquestador
- **coo-orchestrator** — Director de Operaciones / Operaciones
- **cmo-architect** — CMO / Marketing
- **cto-architect** — CTO / Tecnología
- **cio-engineer** — CIO / Infraestructura
- **caio-architect** — Estrategia CAIO/IA

## Components

- **6 agentes**, **7 tareas**, **2 flujos de trabajo**, **1 lista de verificación**

## Requirements

- AIOS >= 4.0.0
