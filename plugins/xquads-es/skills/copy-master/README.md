# Copiar al Maestro

Escuadrón de élite de 33 agentes de redacción — 32 legendarios escritores y expertos en persuasión + 1 orquestador (Copy Master Chief). Este es el v2.0 mejorado del Copy Squad, con 10 nuevos especialistas, ejemplos de campañas reales, una capa de psicología de persuasión en cada proyecto, y cross-specialist patrones de colaboración.

**Version:** 2.0.0

## Inicio rápido

```
@copy-master-chief     Activar el orquestador
*diagnose              # Triage your copywriting request

*collab                # Set up cross-specialist colaboración
```
