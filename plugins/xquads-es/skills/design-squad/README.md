# Design Squad

Equipo de operaciones de diseño — 3 expertos + 4 especialistas + 1 orquestador.

## Inicio rápido

```
@design-chief           Activar el orquestador
*diagnose               # Triage your design challenge
*design-system-creation # Crear un sistema de diseño
*feature-design         # Design a feature end-to-end
```

## Agents (8)

- **design-chief** — Orchestrator
- **brad-frost** - Metodología del diseño atómico
- **dan-mall** — Diseño que escala
- **dave-malouf** — DesignOps leadership
- **ux-designer** — Investigación UX &amp; diseño
- **design-system-architect** - Bibliotecas de componentes
- **visual-generator** Activos visuales
- **ui-engineer** — Producción de códigos de la UI

## Components

* 8 agentes*, 8 tareas*, **2 flujos de trabajo**, **1 lista de verificación*

## Requirements

- AIOS >= 4.0.0
