# Movimiento de escuadrón

7 agentes para la construcción de movimientos que trascienden marcas y productos.

## Inicio rápido

```
@movement-chief   Activar el orquestador
*diagnose         # Triage your movement challenge
*build-movement   # Corriente de trabajo de lanzamiento de movimiento completo
```

## Agents (7)

- **movement-chief** — Orchestrator
- **movement-architect** - Diseño de movimientos
- **fenomenologo** — Análisis de experiencias compartidas
- **identitario** - Formación de identidad
- **estrategista-de-ciclo** - Ciclos de crecimiento
- **manifestador** — Creación del manifiesto
- **analista-de-impacto** - Medición de impacto

## Components

* 7 agentes*, **7 tareas*, **1 flujo de trabajo**, **1 lista de verificación*

## Requirements

- AIOS >= 4.0.0
